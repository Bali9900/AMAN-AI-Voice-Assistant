# AMAN AI Voice Assistant — Android (v1)

## Build APK without installing Android Studio
1. Create a new **public or private GitHub repository**.
2. Upload the **contents** of this folder to the repository root (including the `.github` folder).
3. Open **Actions** → **Build AMAN AI APK** → **Run workflow**.
4. After the workflow succeeds, download the **AMAN-AI-debug-APK** artifact and extract `app-debug.apk`.
5. Install on your Android phone (allow installation from your file manager when prompted).

The debug APK is for testing, not Play Store distribution. GitHub-hosted runners require internet access to download Gradle and Android dependencies.

## Capabilities and limitations
- Android 8.0+; microphone permission required.
- Bengali / Hindi / English recognition via Android's installed speech recognition service. Offline mode is **requested** but is not guaranteed by Android; install language speech packs and verify on your device. Some devices require network even with `EXTRA_PREFER_OFFLINE`.
- "Hey Aman" listening works only while the app is open and foreground. It is **not** a dedicated on-device wake-word engine and does not run on lock screen. Android recognition may pause or time out.
- Offline commands: time, date, camera, settings, alarm screen, torch settings. Torch itself is not toggled. Other AI questions need an online endpoint.
- Online AI: enter a HTTPS OpenAI-compatible chat completions endpoint and an optional API token. This starter uses model `gpt-4o-mini`, so your provider must support that model or the code must be adjusted. The token stays in the current app session; endpoint is saved locally. Do not embed production API secrets in a distributable APK; use an authenticated backend proxy instead.
- Online AI requests send recognized user text to the configured provider. Review the provider's privacy policy.
- Voice replies depend on installed TTS voices. A device may lack Bengali or Hindi TTS data.

## Technical notes
- Kotlin + Android SDK; no Compose dependency; Android Gradle Plugin 8.7.3, Kotlin 2.0.21, Gradle 8.9, Java 17.
- This source has been statically checked for files and ZIP integrity, but **not compiled on this machine** because Android SDK/Gradle are unavailable here. GitHub Actions will report any compile errors.
- Debug APK generated by GitHub Actions is signed with a temporary debug key. Keep data backed up before replacing/reinstalling test builds.
